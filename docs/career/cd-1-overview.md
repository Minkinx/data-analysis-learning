# BI 岗位全景图

> 数据分析与 BI 领域有哪些岗位？各岗位做什么、需要什么技能、天花板在哪？本文帮你梳理清楚。

## 五大岗位概览

| 岗位 | 核心职责 | 主要产出 | 常用工具 |
|------|----------|----------|----------|
| BI 分析师 (BI Analyst) | 报表开发、看板维护、临时取数 | 数据看板、周期性报告 | SQL + Tableau/Power BI + Excel |
| 数据分析师 (Data Analyst) | 业务问题分析、AB 实验、增长分析 | 分析报告、策略建议 | SQL + Python/R + BI 工具 |
| 数据运营 (Data Operations) | 日常数据监控、活动效果评估、渠道分析 | 运营日报、活动复盘 | Excel + SQL + 公司内部平台 |
| 数据产品经理 (Data Product Manager) | BI 平台设计、数据产品规划、埋点规范 | PRD、产品路线图 | Axure/Figma + SQL + 项目管理工具 |
| 数据工程师 (Data Engineer) | 数仓建设、ETL 管道、数据质量保障 | 数据仓库、数据平台 | SQL + Spark/Flink + Airflow + Cloud |

## 岗位详细解析

### BI 分析师（BI Analyst）

- **职责**：负责公司级报表体系和看板的搭建与维护，响应业务方的临时取数需求，确保数据准确及时。
- **核心技能**：SQL（窗口函数、复杂 join、查询优化）+ BI 工具（Tableau/Power BI/Metabase）+ 业务理解。
- **常见场景**：搭建销售日报、财务月报、运营核心指标看板；排查报表数据不一致的原因。
- **天花板**：如果止步于"接需求画报表"，容易被工具取代；向上需要具备分析思维，从"做什么报表"走向"业务需要什么指标"。

### 数据分析师（Data Analyst）

- **职责**：主动发现业务问题，通过数据分析驱动决策，通常深度参与产品迭代和运营策略。
- **核心技能**：SQL + Python（pandas、numpy、scipy）+ 统计学（假设检验、回归分析）+ AB 实验设计 + 业务洞察。
- **常见场景**：评估新功能上线效果、分析用户流失原因、搭建业务指标体系。
- **天花板**：对业务理解深度要求高，如果停留在"描述性分析"层面，价值有限；进阶方向是数据科学或策略产品方向。

### 数据运营（Data Operations）

- **职责**：偏业务侧的数据支持，负责日常运营数据的追踪、活动效果评估、渠道 ROI 分析等。
- **核心技能**：Excel（透视表、vlookup）+ SQL（基础查询）+ 业务理解 + 沟通表达。
- **常见场景**：每日更新业务日报、分析各渠道获客成本、评估大促活动 ROI。
- **天花板**：如果只做数据搬运，成长空间有限；向分析方向转型需要补充统计学和编程能力。

### 数据产品经理（Data Product Manager）

- **职责**：规划数据类产品（BI 平台、标签系统、埋点平台、A/B 测试平台），输出 PRD，推动跨团队落地。
- **核心技能**：产品思维 + SQL（基本查询能力）+ 数据仓库常识 + 项目管理 + 沟通协调。
- **常见场景**：设计内部 BI 平台的功能迭代、梳理埋点规范文档、规划用户画像标签体系。
- **天花板**：需要同时懂数据技术和业务，相对稀缺；但需要持续跟进数据技术趋势，否则产品方案容易落后。

### 数据工程师（Data Engineer）

- **职责**：建设和管理数据基础设施，包括数仓建模、ETL 开发、数据管道运维、数据质量监控。
- **核心技能**：SQL（精通）+ 编程（Python/Java/Scala）+ 大数据框架（Spark/Flink/Hive）+ 调度工具（Airflow/Dagster）+ 云平台。
- **常见场景**：设计星型/雪花型模型、搭建实时数据管道、排查数据延迟或质量异常。
- **天花板**：技术门槛高，就业面广；但纯技术路线可能离业务越来越远，资深后选择管理或架构方向。

## 薪资与天花板对比

薪资水平因城市、行业、公司规模差异较大，以下为一线城市（北京/上海/深圳）的参考范围：

| 岗位 | 0-2 年 | 3-5 年 | 5-8 年 | 8 年+ | 天花板瓶颈 |
|------|--------|--------|--------|-------|------------|
| BI 分析师 | 8-15K | 15-25K | 25-35K | 35-45K（管理岗） | 容易陷入工具化，需要向分析转型 |
| 数据分析师 | 10-18K | 18-30K | 30-50K | 50-80K+（专家/管理） | 业务理解深度决定上限 |
| 数据运营 | 8-12K | 12-20K | 20-30K | 30-40K（运营管理） | 偏执行，需补技术能力转型 |
| 数据产品经理 | 12-18K | 20-35K | 35-55K | 55-80K+（产品总监） | 岗位稀少，需要懂技术又懂业务 |
| 数据工程师 | 12-20K | 25-40K | 40-60K | 60-90K+（架构/管理） | 技术迭代快，需要持续学习 |

> 注：薪资为税前月薪参考值，互联网行业通常高于传统行业，大厂会额外有股票/期权。

## 行业差异

- **互联网**：数据分析岗位最成熟，用户行为分析、AB 实验、增长分析是核心场景；薪资天花板最高，但也最卷。
- **金融 / 银行**：风控、反欺诈、客户画像为主；工作稳定，技术栈偏传统（Oracle + SAS），转型互联网需要更新技能。
- **零售 / 消费品**：进销存、会员分析、促销评估；节奏相对温和，数据量级较小，适合入门。
- **制造业 / 传统企业**：生产报表、供应链优化、质量分析；正在数字化转型中，岗位需求增加但薪资偏低。

## 如何选择方向

没有"最好"的岗位，只有最适合你的切入方向：

| 你的背景 / 偏好 | 推荐方向 |
|-----------------|----------|
| 擅长沟通、喜欢跟业务打交道 | 数据分析师 / 数据运营 |
| 喜欢做产品、画原型、推动落地 | 数据产品经理 |
| 喜欢技术、写代码、搭系统 | 数据工程师 |
| 喜欢做报表、追求数据准确性 | BI 分析师 |
| 想做数据科学、机器学习方向 | 数据分析师 → 数据科学家（进阶） |

## 常见职业转型路径

```
BI 分析师 ──→ 数据分析师 ──→ 资深分析师 / 数据科学家
      ↘              ↘
        数据运营 ────→ 业务运营 / 策略运营
              ↘
                数据产品经理 ──→ 数据产品总监
                      ↘
                        数据工程师 ──→ 数据架构师 / 技术管理
```

**建议**：入门阶段可以从 BI 分析师或数据运营切入，积累业务理解和数据 sense 后再横向迁移；擅长技术可直接走数据工程路线；产品感好的可以尝试数据产品经理方向。

> 不管选哪条路，SQL 都是基本功，业务理解都是持久竞争力。先深耕一个方向，有余力再拓展周边能力。
