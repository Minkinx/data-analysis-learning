# 能力成长路线

> 数据分析职业发展通常经历四个阶段：执行层 → 独立层 → 策略层 → 领导层。每个阶段的核心能力要求不同。

## 四个阶段概览

| 阶段 | 年限 | 角色定位 | 典型产出 |
|------|------|----------|----------|
| 初级 (Junior) | 0-2 年 | 执行者 — 按要求完成数据提取和报表 | SQL 查询、Excel 报表、简单的看板 |
| 中级 (Mid) | 2-5 年 | 独立贡献者 — 主动发现问题并推动解决 | 专题分析报告、指标体系、实验评估 |
| 高级 (Senior) | 5-8 年 | 策略制定者 — 驱动业务方向和数据产品建设 | 业务策略建议、数据产品规划、团队辅导 |
| 专家/管理 (Expert/Manager) | 8 年+ | 方向制定者 — 搭建团队和数据文化 | 数据战略、组织搭建、方法论沉淀 |

## 第一阶段：初级 (0-2 年) — 执行层

这个阶段的核心是 **快、准、稳** 地完成任务。

**技能 checklist**

| 技能 | 要求 | 说明 |
|------|------|------|
| SQL 基础查询 | ★★★ | SELECT、WHERE、JOIN、GROUP BY、子查询，能独立完成取数需求 |
| SQL 进阶 | ★★★ | 窗口函数、CTE、查询优化、常见面试题通过 |
| Excel 数据分析 | ★★★ | 透视表、vlookup、条件格式、基础图表 |
| BI 工具入门 | ★★☆ | 能用 Tableau/Power BI 搭建简单看板 |
| 业务理解 | ★★☆ | 理解自己负责的业务模块的核心指标 |
| 沟通执行 | ★★★ | 准确理解需求、按时交付、有问题及时反馈 |

**典型工作内容**

- 根据需求文档写 SQL 提取数据
- 维护和更新日报 / 周报
- 搭建基本的业务看板
- 对数据进行一致性校验

## 第二阶段：中级 (2-5 年) — 独立层

这个阶段的目标是 **从"执行"走向"分析"**，能够独立发现问题并给出 actionable 的建议。

**技能 checklist**

| 技能 | 要求 | 说明 |
|------|------|------|
| 统计学 | ★★★ | 描述统计、假设检验、AB 实验基础、回归分析 |
| Python/R | ★★★ | pandas 数据处理、matplotlib/seaborn 可视化、基础的统计分析 |
| 指标体系 | ★★★ | 能独立搭建 OSM/UJM 模型，设计核心指标和过程指标 |
| 专题分析 | ★★★ | 能独立完成从问题定义→数据获取→分析→结论→建议的闭环 |
| AB 实验 | ★★☆ | 了解实验设计原则、样本量计算、结果解读 |
| 项目管理 | ★★☆ | 同时处理多个需求，能合理安排优先级 |
| 沟通影响 | ★★★ | 能用数据和故事说服 stakeholders |

**典型工作内容**

- 深度用户行为分析（留存、转化路径、分层）
- 产品功能上线效果评估
- 参与搭建公司核心指标体系
- 向业务方呈现分析结论并推动落地

## 第三阶段：高级 (5-8 年) — 策略层

这个阶段从"分析"走向"策略"，**驱动业务方向**，帮助团队做更重要的决策。

**技能 checklist**

| 技能 | 要求 | 说明 |
|------|------|------|
| 商业思维 | ★★★ | 理解公司战略、行业格局，分析能直接关联业务目标 |
| 数据产品 | ★★★ | 能主导内部 BI 平台／标签系统／实验平台的产品规划 |
| 实验与因果推断 | ★★★ | 能设计复杂的实验（MVT、Geo 实验），处理辛普森悖论等问题 |
| 团队辅导 | ★★☆ | 能指导初中级分析师，做代码 review 和分析框架 review |
| 跨部门推动 | ★★★ | 能推动中大型项目跨团队协作落地 |
| 向上汇报 | ★★★ | 能从数据中提炼关键结论，用简洁的方式向 VP/CXO 汇报 |

**典型工作内容**

- 参与业务年度规划，输出数据维度的策略建议
- 搭建数据产品体系，提升团队数据效率
- 辅导初中级分析师，建立团队分析规范
- 负责跨 BU 的数据治理和统一口径项目

## 第四阶段：专家/管理 (8 年+) — 领导层

这个阶段的核心是 **制定方向、搭建团队、构建文化**。

**技能 checklist**

| 技能 | 要求 | 说明 |
|------|------|------|
| 数据战略 | ★★★ | 制定团队 1-3 年数据建设规划，匹配业务节奏 |
| 组织建设 | ★★★ | 搭建团队架构、招聘标准、晋升体系 |
| 数据文化 | ★★★ | 在公司层面推动数据驱动文化，提升全员数据素养 |
| 行业影响力 | ★★☆ | 通过文章、演讲、开源等方式建立个人或团队影响力 |
| 管理能力 | ★★★ | 目标设定、绩效管理、团队激励、冲突处理 |

**典型工作内容**

- 制定数据团队年度目标和 OKR
- 招聘和培养中高级数据人才
- 建设公司级数据平台和数据治理体系
- 向管理层汇报数据战略进度

## 成长建议

1. **不要只看年限**：成长不是线性的，关键看你能不能产出下一阶段的价值。有人 3 年就达到高级水平，有人 8 年还在初中级。
2. **定期做 gap analysis**：每半年回顾一次 checklist，找出当前最短板，集中突破。
3. **横向迁移是常态**：数据分析师可以转向数据产品、数据科学、甚至业务运营。技术线和管理线各有优劣，根据自身偏好选择。
4. **软技能和硬技能同样重要**：越往上走，沟通、影响、管理能力的权重越高。
