# 学习资源推荐

> 持续学习是数据分析师的必修课。这里整理了书籍、课程、社区和开源资源，覆盖不同方向和学习阶段。

## 推荐书籍

### SQL

| 书名 | 适合阶段 | 推荐理由 |
|------|----------|----------|
| 《SQL 必知必会》 | 入门 | 快速上手 SQL 基础语法，适合零基础 |
| 《SQL 经典实例》 | 初中级 | 大量实战场景，从简单查询到窗口函数 |
| 《High Performance SQL》 | 中高级 | 查询优化、索引设计、执行计划分析 |

### Python 数据分析

| 书名 | 适合阶段 | 推荐理由 |
|------|----------|----------|
| 《Python编程从入门到实践》 | 入门 | Python 基础+项目实战 |
| 《利用Python进行数据分析》 | 初中级 | pandas 作者亲笔，数据处理必读 |
| 《Python数据科学手册》 | 中高级 | 覆盖 numpy/pandas/matplotlib/scikit-learn |

### 统计学与分析方法

| 书名 | 适合阶段 | 推荐理由 |
|------|----------|----------|
| 《赤裸裸的统计学》 | 入门 | 没有公式的统计学入门，建立直觉 |
| 《深入浅出统计学》 | 入门 | 图文并茂，适合自学的统计学教材 |
| 《商务与经济统计》 | 中高级 | 系统全面的统计学教材，覆盖假设检验、回归、时间序列 |
| 《精益数据分析》 | 中高级 | 面向互联网业务的分析方法论和指标框架 |

### AB 实验与因果推断

| 书名 | 适合阶段 | 推荐理由 |
|------|----------|----------|
| 《AB实验：科学归因与增长的藏宝图》 | 初中级 | 中文写作，系统讲解 AB 实验全流程 |
| 《Trustworthy Online Controlled Experiments》 | 中高级 | Google 科学家撰写，在线实验权威参考 |
| 《Causal Inference: The Mixtape》 | 中高级 | 因果推断入门，理论和代码结合 |

### 数据可视化与 Storytelling

| 书名 | 适合阶段 | 推荐理由 |
|------|----------|----------|
| 《用数据讲故事》 | 全阶段 | 从图表选择到叙事结构，每个分析师都该读 |
| 《The Visual Display of Quantitative Information》 | 中高级 | Edward Tufte 经典，数据可视化美学 |
| 《Storytelling with Data》 | 全阶段 | 数据叙事实战指南，含大量对比案例 |

## 开源项目与数据集

| 名称 | 地址 | 说明 |
|------|------|------|
| Olist Brazilian E-commerce | Kaggle | 电商数据，适合练习 SQL 和 RFM 分析 |
| Google Analytics Sample Dataset | BigQuery public data | Google Analytics 样本，产品分析绝佳练习 |
| NYC Taxi Trips | BigQuery / Kaggle | 百亿级数据量，适合练习查询优化和 ETL |
| TPC-H / TPC-DS | 标准数据集 | OLAP 性能测试标准，适合数仓建模练习 |
| dbt (data build tool) | GitHub | 开源的数据转换工具，学习数据建模和工程的实战项目 |
| Superset | GitHub | Apache 开源 BI 工具，可本地部署学习和二次开发 |

## 学习路径建议

- **入门阶段**：SQL 必知必会 + Google Data Analytics Certificate → 在 Kaggle 做两个项目
- **进阶阶段**：《利用Python进行数据分析》+ 《精益数据分析》→ 通读 Towards Data Science 每周精华
- **高级阶段**：《Trustworthy Online Controlled Experiments》+ CDMP → 参与 dbt/Superset 等开源项目

> 资源在精不在多。每类资源挑 1-2 个吃透，比收藏 100 个链接有价值得多。
