# 💡 职业发展

> 了解 BI 相关岗位全景，规划你的能力成长路径，获取优质学习资源，掌握职场软技能。

数据分析与 BI（Business Intelligence）领域岗位分工日渐细化。从执行层的取数、报表，到策略层的业务决策、数据产品，再到管理层的数据文化构建，每一条路径都有不同的能力和技能要求。本专栏从四个角度帮助你梳理职业发展方向：

- **[岗位全景图](./cd-1-overview)** — BI 分析师 / 数据分析师 / 数据运营 / 数据产品经理 / 数据工程师，看清各岗位的职责、技能要求和天花板。
- **[能力成长路线](./cd-2-growth-path)** — 初 / 中 / 高 / 专家 / 管理各阶段的 checklist，帮你定位当前阶段并找到下一步。
- **[学习资源推荐](./cd-3-resources)** — 书籍、课程、认证、社区和开源项目，持续充电的清单。
- **[职场软技能](./cd-4-soft-skills)** — 需求沟通、跨团队协作、向上汇报和时间管理，从"能做"到"能成"的关键能力。

> 建议先通读岗位全景图，找到适合自己的方向，再对照成长路线制定学习计划。
