# 面试专区

> BI 数据分析岗面试全题型覆盖，从技术面到业务面系统准备。本专区按知识领域划分为七大模块，覆盖 SQL、Python、统计学、Case Study、Product Sense、行为面试和面试策略，帮助你一站式备战数据岗面试。

## 推荐学习路径

### 按级别

- **实习生 / 校招**: IP 1 (入门-中级) -> IP 2 -> IP 3 -> IP 6
- **1-3 年经验**: IP 1 (中级-进阶) -> IP 3 -> IP 4 -> IP 5 -> IP 6
- **3-5 年经验**: IP 1 (进阶-困难) -> IP 3 -> IP 4 -> IP 5 -> IP 6 -> IP 7
- **5 年以上 / 带团队**: IP 4 -> IP 5 -> IP 7（侧重策略和领导力题）

### 按公司类型

- **互联网大厂**（字节/腾讯/阿里/美团）：SQL > Case Study > Product Sense > 统计学
- **外企**（Microsoft/Amazon/Google）：Product Sense > 统计学 > SQL > 行为面试
- **创业公司 / 中型互联网**：SQL > Python > 全栈能力展示 > Case Study
- **金融/咨询**：统计学 > 结构化思维 > Case Study > SQL

## 面试流程概览

```
简历筛选 → 技术面（SQL笔试/代码面）→ 业务面（Case Study）→ Product Sense面 → 
交叉面/leader面 → HR面（行为面试+谈薪）
```

不同公司和级别的面试轮次会有差异，建议在准备前先了解目标公司的具体面试流程。

## 如何使用本专区

1. **先做自测**：每个模块都有从易到难的题目，建议从中间难度开始，快速定位薄弱环节
2. **重视模版与框架**：Case Study 和 Product Sense 的核心在于结构化思维，不要死记答案
3. **动手练习**：SQL 和 Python 的题目建议在本地环境实际运行验证
4. **模拟面试**：可以找人互相模拟，或者自己对着录音练习表达
5. **持续更新**：面试题会持续更新，欢迎贡献你的面试真题
