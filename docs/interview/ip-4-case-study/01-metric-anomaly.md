# 指标异动分析

> 指标异动分析是数据分析面试中出现频率最高的 Case 类型。面试官通常会抛出"某核心指标突然下跌/上涨了 X%，请分析原因"这类问题，考察候选人的归因能力和结构化思维。

## 分析框架

### 1. 确认异动 (Verify the Anomaly)

先确认"是不是真的有问题"：

| 检查项 | 说明 |
|--------|------|
| 数据口径 | 计算方式是否有变更？埋点是否有异常？ |
| 时间口径 | 是否同比/环比？是否是季节性波动？ |
| 异常程度 | 偏离正常范围多少？是否在 3σ 之外？ |
| 对比基准 | 是否有其他可对照的指标（如 DAU 跌了，PV 是否也跌了？） |

### 2. 维度拆解 (Dimension Breakdown)

从多个维度拆解，定位"跌在哪"：

| 维度分类 | 具体维度 |
|----------|----------|
| 时间 | 小时级 / 天级 / 周级趋势，同比 vs 环比 |
| 用户 | 新用户 vs 老用户、渠道来源、用户分层 |
| 地区/城市 | 城市线级、区域分布 |
| 产品/功能 | 页面/模块/功能 |
| 平台 | iOS vs Android、Web vs App |

### 3. 公式拆解

将核心指标拆解为可量化的子指标，例如：

```
DAU = 新用户 + 老用户回流
新用户 = 渠道曝光量 × 点击率 × 注册转化率
老用户 = 昨日留存用户 × 今日留存率
```

```
GMV = 流量 × 转化率 × 客单价
    = UV × 下单转化率 × 平均客单价
    = (新用户 + 老用户) × 转化率 × 客单价
```

### 4. 假设验证 (Hypothesis Testing)

列出可能的根因，逐个验证排除：

| 假设类型 | 例子 |
|----------|------|
| 外部因素 | 竞品活动、政策变化、节假日影响、舆情事件 |
| 内部因素 | 产品改版、运营策略调整、技术故障、营销预算变化 |
| 数据因素 | 埋点错误、计算口径变更、ETL 延迟 |

### 5. 量化结论

对每个确定的根因，量化其影响程度，例如：

```
DAU 下降 10%（绝对值减少 50 万）
- 渠道 A 投放预算缩减：影响 20 万（占 40%）
- 功能 X bug 导致闪退：影响 15 万（占 30%）
- 季节性回落（开学季）：影响 10 万（占 20%）
- 其他/未知因素：影响 5 万（占 10%）
```

## 案例 1：DAU 连续 3 天下降 8%

**场景**：你是某内容社区 App 的数据分析师，发现过去 3 天 DAU 从 500 万下降到 460 万，降幅约 8%。请分析原因。

### 分析过程

**Step 1: 确认异动**
- 确认数据埋点无异常，ETL 正常
- 对比历史同期：去年同期也有类似幅度波动，但幅度较小（约 3-5%）
- 对比关联指标：新用户注册量下降 15%，老用户活跃度下降 5%

**Step 2: 维度拆解**

先从时间维度看：
```
Day -7 to Day -4: DAU 稳定在 495-505 万
Day -3: DAU 485 万（↓3%）
Day -2: DAU 470 万（↓3%）
Day -1: DAU 460 万（↓2%）
```
是在**持续恶化**，而非一次性下跌。

从用户维度看：
| 用户群 | 降幅 | 占整体 DAU 比例 |
|--------|------|----------------|
| 新用户（注册 < 7 天） | -25% | 15% |
| 活跃用户（7-30 天） | -8% | 25% |
| 核心用户（> 30 天） | -2% | 60% |

**主要矛盾在新用户**。

从渠道维度看：
| 渠道 | 新用户量变化 | 获客成本变化 |
|------|-------------|-------------|
| 信息流广告 | -40% | +50% |
| 搜索 ASO | -5% | — |
| 社交裂变 | -10% | — |
| 品牌合作 | +5% | — |

**信息流广告新用户大幅减少**。

**Step 3: 假设验证**

假设 A：信息流广告投放预算缩减 → **与渠道团队确认属实，预算缩减 35%**
假设 B：广告素材效果下降 → **检查 CTR，从 2% 下降到 1.8%，影响较小**
假设 C：竞品加大了投放 → **确认竞品同期增加了 30% 广告预算**
假设 D：产品功能导致老用户流失 → **老用户活跃度仅降 2%，排除**

**Step 4: 结论**

- **根因 1（主要原因）**：信息流广告预算缩减 35% + 竞品加大投放，导致新用户获取量下降 40%，贡献 DAU 降幅约 5 个百分点（占整体降幅的 62.5%）
- **根因 2（次要原因）**：自然增长的季节性回落（开学季），贡献降幅约 2 个百分点（占 25%）
- **其他**：随机波动约 1 个百分点（占 12.5%）

**Step 5: 行动建议**

短期：
- 评估恢复广告预算的 ROI，建议在一周内追加预算
- 优化广告定向和素材，提升 CTR 和转化率
- 加大社交裂变等低成本渠道的投放

长期：
- 建立多渠道获客体系，降低单一渠道依赖
- 完善归因模型，更准确评估各渠道的 LTV
- 建立 DAU 异动自动告警和归因系统

## 案例 2：电商 GMV 周末异常下跌

**场景**：你是某电商平台的数据分析师。通常周末 GMV 会比工作日高 20%，但本周末 GMV 与工作日持平，请分析。

### 快捷版分析框架

```python
# 分析思路的伪代码
def analyze_gmv_drop():
    # 1. 公式拆解
    GMV = UV * 转化率 * 客单价

    # 2. 检查各因子
    if UV.drop():
        check_channel()      # 哪个渠道流量下降？
        check_campaign()     # 运营活动是否正常？
    if 转化率.drop():
        check_price()        # 价格竞争力
        check_competitor()   # 竞品是否大促
        check_tech()         # 有没有报错
    if 客单价.drop():
        check_product_mix()  # 商品结构是否变化

    # 3. 内外部排查
    内部 = [产品改版, 运营活动, 价格调整, 技术故障]
    外部 = [竞品动态, 节日影响, 物流延迟]

    return 归因结论
```

**关键洞察点**：
- 检查"支付成功率"——经常被忽略的技术因素
- 确认是否因大促预热导致用户持币待购（本周末不买等下周活动）
- 检查竞品是否有超级品牌日或百亿补贴

## 常见面试追问

1. **"如果你发现 DAU 下降的原因是渠道 A 的投放下降，但团队说预算不能增加，你会怎么做？"**
   → 转向优化投放效率、探索免费渠道、做用户唤醒

2. **"如何区分是产品问题还是运营问题？"**
   → 分组对比：受影响的用户 vs 未受影响的用户；是否有灰度发布

3. **"量化影响时，如果多个因素同时变化，如何分离各自贡献？"**
   → 逐步回归、贡献度分解、对照实验

4. **"这个分析如果用自动化系统来实现，你会怎么设计？"**
   → 指标监控 → 异动检测 → 维度下钻 → 根因推荐 → 行动建议
