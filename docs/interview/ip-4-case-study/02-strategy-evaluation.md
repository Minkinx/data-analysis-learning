# 业务策略评估

> 策略评估类 Case 考察候选人是否能科学、客观地衡量某项业务策略的效果。常见场景包括营销活动效果评估、产品功能上线评估、补贴策略评估等。

## 核心方法论

### 因果推断框架

评估一项策略的效果，本质是回答反事实问题："如果没做这个策略，结果会怎样？"

```
效果 = 实际结果 - 反事实结果（如果没有该策略）
```

| 方法 | 适用场景 | 关键假设 |
|------|----------|----------|
| A/B 测试 (RCT) | 可随机分组 | 随机化有效 |
| 双重差分 (DID) | 有自然实验组 | 平行趋势假设 |
| 断点回归 (RDD) | 策略基于阈值 | 阈值附近无操控 |
| 匹配法 (PSM) | 观察数据 | 无未观测混杂因素 |
| 合成控制 (SCM) | 单一实验组 | 合成组合理 |

### 评估维度

```
策略评估 = 效果 (Effectiveness) + 效率 (Efficiency) + 可持续性 (Sustainability)
```

| 维度 | 关键问题 | 典型指标 |
|------|----------|----------|
| 效果 | 策略是否达到目标？ | 核心指标变化、统计显著性 |
| 效率 | 投入产出比如何？ | ROI、边际收益、CAC 变化 |
| 可持续性 | 效果是暂时还是长期的？ | 衰减曲线、用户习惯变化 |
| 溢出效应 | 对周边业务的影响？ | 交叉销售、蚕食效应 |
| 风险 | 是否有负面效果？ | 用户体验下降、坏账增加 |

## 案例 1：补贴活动效果评估

**场景**：某电商平台在 3 月推出"满 100 减 20"的补贴活动。作为数据分析师，请评估活动效果。活动数据如下：

| 指标 | 活动前 (2月) | 活动中 (3月) | 活动后 (4月) |
|------|-------------|-------------|-------------|
| 日均 GMV | 1000 万 | 1350 万 | 1050 万 |
| 日均订单量 | 8 万 | 11 万 | 8.5 万 |
| 客单价 | 125 元 | 123 元 | 124 元 |
| 用户数 (日活) | 50 万 | 52 万 | 51 万 |
| 补贴成本 | 0 | 220 万/天 | 0 |

### 分析过程

**Step 1: 明确问题**

评估目标：补贴活动是否"成功"？需要从多个维度综合判断。

**Step 2: 效果评估**

| 指标 | 变化 | 解读 |
|------|------|------|
| GMV 增量 | +350 万/天 | 短期效果明显 |
| 订单量增量 | +3 万/天 | 订单增长驱动 GMV |
| 客单价变化 | -2 元 | 轻微下降，说明用户凑单行为有限 |
| 用户数 | +2 万/天 | 新客吸引和沉默唤醒有效果 |

**Step 3: 效率评估**

```
增量 ROI 计算：
增量 GMV = 1350 - 1000 = 350 万/天
补贴成本 = 220 万/天
增量 ROI = (350 - 220) / 220 = 59%

但需要考虑自然增长：
同期的自然增长率 ≈ 5%（基于历史趋势）
自然增长 GMV = 1000 * 5% = 50 万/天
归因于活动的增量 GMV = 350 - 50 = 300 万/天
调整后 ROI = (300 - 220) / 220 = 36.4%
```

**Step 4: 可持续性评估**

活动结束后：
- GMV 回落至 1050 万（比活动前高 5%，部分用户习惯保留）
- 用户数仍比活动前多 1 万（部分新用户留存）
- 订单量比活动前高 0.5 万

**Step 5: 拆解效果来源**

区分"新增用户" vs "存量用户"的增量贡献：
- 新增用户（活动期间首次下单）：贡献 30% 增量 GMV
- 存量用户（之前下过单）：贡献 50% 增量 GMV
- 沉默唤醒用户（30 天+未下单）：贡献 20% 增量 GMV

**Step 6: 结论与建议**

**总体评价**：活动效果中性偏正面
- 短期拉动 GMV 明显，ROI 约 36%
- 对用户增长有一定帮助（新增 + 唤醒）
- 但补贴成本较高，且效果不可持续

**建议**：
1. 优化补贴门槛和力度，找到性价比最优的点（梯度补贴测试）
2. 对新增用户做二次转化（首单后推送优惠券提高留存）
3. 建立补贴策略的自动化 ROI 监控体系

## 案例 2：搜索推荐算法改版评估

**场景**：某内容平台的推荐算法进行改版（新版本的 CTR 预估模型上线）。作为分析师，请设计方案评估改版效果。

### 评估方案

**Step 1: 实验设计**

采用 A/B 测试，分层随机抽样：
- 对照组：旧算法
- 实验组：新算法
- 实验周期：至少 2 周（含 2 个完整周末）
- 样本量：基于 MDE 计算（如果预期 CTR 提升 5%，α=0.05，β=0.20）

**Step 2: 核心指标体系**

| 分类 | 指标 | 预期方向 |
|------|------|----------|
| 核心指标 | CTR（点击率）、人均阅读时长 | 正向 |
| 用户体验 | 跳出率、负面反馈率、内容多样性 | 中性/正向 |
| 商业指标 | 广告收入、用户付费转化 | 需关注 |
| 系统指标 | 推荐响应时间、计算资源消耗 | 中性 |

**Step 3: 注意陷阱**

- **Novelty Effect**：新改动初期可能效果较好，需要足够实验周期
- **指标互斥**：CTR 提升可能因为推荐了"标题党"，但用户体验下降
- **Segmentation**：新算法对不同用户群的效果可能不同（如新用户 vs 老用户）

**Step 4: 深度分析**

```python
# 分层分析示例
def analyze_segmentation(exp_data):
    segments = {
        '新用户': exp_data[exp_data['注册天数'] <= 7],
        '活跃用户': exp_data[(exp_data['注册天数'] > 7) & (exp_data['活跃天数'] > 10)],
        '沉默用户': exp_data[exp_data['活跃天数'] <= 3]
    }
    
    results = {}
    for name, group in segments.items():
        ctr_diff = group[group['组别'] == '实验']['CTR'].mean() - \
                   group[group['组别'] == '对照']['CTR'].mean()
        results[name] = ctr_diff
    
    return results
```

**Step 5: 长期效果的代理指标**

由于不能长时间 A/B，需要找到长期效果的代理指标：
- 次日留存 → 衡量推荐质量
- 7 日活跃天数 → 衡量用户粘性
- 内容消费深度 → 衡量推荐的相关性

### 结论与建议

- 如果核心指标显著正向且用户体验指标无显著负向 → 全量上线
- 如果分群效果不一致 → 分群上线（对新用户用新版）
- 如果短期效果明显但长期指标有问题 → 继续优化，暂不全量

## 常见面试追问

1. **"没有做 A/B 测试的条件下，如何评估策略效果？"**
   → 使用 DID、PSM、SCM 等准实验方法，讨论各自的局限性

2. **"如何判断效果是活动带来的还是自然增长？"**
   → 构建反事实：时间序列预测（ARIMA/Prophet）、合成控制法

3. **"如何衡量补贴的边际效益递减点？"**
   → 不同补贴力度下的 A/B 测试、弹性分析

4. **"活动效果在渠道间有差异，如何归因？"**
   → 多渠道归因模型（last-click / Shapley / 马尔可夫链）
