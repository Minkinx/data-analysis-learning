# 费米估算 (Fermi Estimation)

> 费米估算题是数据分析面试中的经典题型，考察候选人的逻辑拆解能力、数量级敏感度和假设合理性。题目通常看起来无从下手（如"北京有多少个加油站"），但通过合理的逻辑链条和近似，可以得到一个数量级正确的估计。

## 核心方法论

### 估算公式

```
答案 = 已知量 × 合理假设的乘积
```

### 四大原则

| 原则 | 说明 |
|------|------|
| 逻辑拆解 | 将复杂问题拆解为可估算的子问题 |
| 合理假设 | 每个假设都要有依据（经验值/常识/类比） |
| 数量级正确 | 不追求精确，确保在 10 倍以内即可 |
| 交叉验证 | 用不同方法估算同一个值，看是否吻合 |

### 常用参考值

| 类别 | 参考值 |
|------|--------|
| 中国人口 | 14 亿 |
| 北京人口 | ~2200 万 |
| 上海人口 | ~2500 万 |
| 家庭平均规模 | ~3 人 |
| 小汽车保有量（中国） | ~3 亿 |
| 每人日均用水 | ~150L |
| 每人日均餐饮消费 | ~50 元 |
| 便利店日均客流 | ~500 人 |

## 案例 1：北京有多少个加油站？

**思路拆解**：

北京需要加油站的车辆数 / 每个加油站能服务的车辆数

**Step 1: 估算北京汽车数量**

```
北京人口 ≈ 2200 万
家庭平均人数 ≈ 3 人/户
家庭总数 ≈ 2200 / 3 ≈ 730 万户

假设 60% 家庭有车，加上出租车/网约车/货车 ≈ 50 万辆
北京汽车总数 ≈ 730 × 60% + 50 ≈ 490 万辆

交叉验证：北京机动车保有量官方数据 ≈ 600 万辆（含摩托车等）
取 500 万辆作为工作值。
```

**Step 2: 估算每辆车的加油频率**

```
假设平均每辆车每两周（14 天）加一次油
每辆车年加油次数 = 365 / 14 ≈ 26 次/年
```

**Step 3: 估算每个加油站的日服务能力**

```
一个加油站假设有 4 个加油位
每个加油位加一次油 ≈ 5 分钟（含排队等待）
加油站营业时间 ≈ 16 小时/天（早 7 点到晚 11 点）

每天最多服务车辆 = 4 个加油位 × (16小时 × 60分钟 / 5分钟)
= 4 × 192 ≈ 768 辆/天

实际利用率 ≈ 60%（不是所有时间都满负荷）
每个加油站日均实际服务 ≈ 768 × 60% ≈ 460 辆/天
```

**Step 4: 计算加油站数量**

```
北京每天需要加油的车辆数 = 500 万 / 14 = 35.7 万辆/天
需要的加油站数 = 35.7 万 / 460 ≈ **776 个**

加上郊区/高速公路上的加油站，大约 800-1000 个
```

**答案范围**：约 800-1200 个。

**实际参考**：北京加油站约 1100 个左右（数据来源：商务部）。

## 案例 2：上海星巴克有多少家？

**思路拆解**：从需求和供给两个角度交叉验证。

**方法一：从需求角度（人均法）**

```
上海人口 ≈ 2500 万
假设每天喝咖啡的人群比例 ≈ 15%（一线城市咖啡渗透率）
每天喝咖啡的人数 ≈ 2500 × 15% = 375 万人

假设其中 40% 选择星巴克 ≈ 150 万人/天
平均每个用户每天服务客数？星巴克单店日均 ≈ 400-600 杯
单店日均服务咖啡消费者 ≈ 200 人（算上 share 和非咖啡消费者）

星巴克数量 = 150 万 / 200 ≈ **750 家**
```

**方法二：从供给角度（面积法）**

```
上海面积 ≈ 6340 平方公里
假设核心城区（浦西七区 + 浦东核心）≈ 1000 平方公里
星巴克覆盖主要在核心城区和商圈

取每 3 平方公里一家星巴克（核心区更密，郊区更疏）
核心城区星巴克 ≈ 1000 / 3 ≈ 333 家
郊区按核心城区的 30% ≈ 100 家
加上交通枢纽/景点 ≈ 50 家

估测 ≈ 333 + 100 + 50 ≈ **480 家**（偏保守）
```

**综合估计**：取两种方法的中间值，约 600-700 家。

**实际参考**：上海星巴克约 900+家（全球星巴克最多的城市）。

## 案例 3：北京地铁一天的客运量是多少？

**思路拆解**：按线路×班次×载客量的方法。

**Step 1: 估算运营线路和班次**

```
北京地铁运营线路 ≈ 27 条
假设平均每条线路双向运营，高峰期 2 分钟一班，平峰期 5 分钟一班
平均间隔 ≈ 3.5 分钟
单方向每小时班次 ≈ 60 / 3.5 ≈ 17 班
每天运营时间 ≈ 19 小时（早 5 点到凌晨 0 点）

高峰时段 ≈ 4 小时（早 7-9，晚 17-19）
平峰时段 ≈ 15 小时
```

**Step 2: 估算每列车载客量**

```
一列地铁 ≈ 6 节车厢
每节车厢 ≈ 200 人（拥挤时）
满载率 ≈ 70%（平峰）到 120%（高峰）

高峰每列车 ≈ 6 × 200 × 120% ≈ 1440 人
平峰每列车 ≈ 6 × 200 × 70% ≈ 840 人
```

**Step 3: 计算单线日客运量**

```
高峰 4 小时 × 17 班/小时 × 1440 人/单方向 × 2 方向 = 195,840 人
平峰 15 小时 × 17 班/小时 × 840 人/单方向 × 2 方向 = 428,400 人
单线日客运量 ≈ 62 万人次/条

但实际不同线路差异大（1 号线 vs 郊区线）
加权平均取 60% 的满载率水平 ≈ 37 万人次/条/日
```

**Step 4: 总量估算**

```
北京地铁日客运量 ≈ 27 条 × 37 万 ≈ **1000 万人次/日**
```

**实际参考**：北京地铁日客运量在 1000-1300 万人次之间。估算在正确数量级。

## 其他经典费米估问题

| 题目 | 核心拆解思路 | 参考答案范围 |
|------|-------------|-------------|
| 中国一年消耗多少瓶可乐？ | 人均 × 人口 × 频率 | 约 600-800 亿瓶 |
| 北京有多少个理发店？ | 人口 / 每个理发师服务用户数 | 约 2-3 万个 |
| 上海每天产生多少吨垃圾？ | 人均 × 人口 | 约 2-3 万吨 |
| 一架波音 747 能装多少个乒乓球？ | 机舱体积 / 乒乓球体积 × 填充率 | 约 5000 万个 |
| 抖音一天的用户使用总时长？ | DAU × 人均使用时长 | 约 10-15 亿小时 |
| 中国一年消耗多少张 A4 纸？ | 办公人均 × 白领人数 + 学校用量 | 约 2000-3000 亿张 |

## 估算技巧总结

1. **记住关键基数**：中国人口 14 亿、北京人口 2200 万、平均家庭 3 人
2. **从大到小拆解**：先用人数、再用比例、再用频次
3. **多方法交叉验证**：从供给侧估一次，从需求侧估一次
4. **不要在一处精确**：每个环节保持 2 倍以内的精度即可，最终数量级正确
5. **边算边复查**：结果是否合理？是否符合常识？
6. **大声说出你的思考过程**：面试官更看重逻辑链条，而非最终数字
