# KM 5. 分析方法论（Analysis Methods）

> 分析方法论是数据分析师的核心实战工具集。从用户行为视角出发，本节覆盖漏斗分析、同期群、留存、分层、归因、异动检测、LTV 等经典方法，以及电商、内容、金融、SaaS 四大行业的专题分析场景。

## 章节

1. [漏斗分析](/knowledge-map/km-5-analysis-methods/01-funnel) — 转化率计算、流失节点识别、漏斗对比、开放 vs 闭合漏斗、步骤归因
2. [同期群分析](/knowledge-map/km-5-analysis-methods/02-cohort) — 时间/行为同期群定义、留存/收入/活跃度三类型、矩阵可视化与解读
3. [留存分析](/knowledge-map/km-5-analysis-methods/03-retention) — Day N / Rolling / Bracket 留存、留存曲线、幸存者分析、流失预测框架
4. [用户分层](/knowledge-map/km-5-analysis-methods/04-user-segmentation) — RFM 模型、K-Means 聚类分层、策略映射、动态 vs 静态分层
5. [归因分析](/knowledge-map/km-5-analysis-methods/05-attribution) — 末次/首次/线性/时间衰减/位置归因、Shapley Value、数据驱动模型、选型对比
6. [异动分析](/knowledge-map/km-5-analysis-methods/06-anomaly-detection) — 加乘拆解、贡献度下钻、同比/环比/同周对比、Z-Score / CUSUM 检测
7. [LTV 分析](/knowledge-map/km-5-analysis-methods/07-ltv) — 历史与预测 LTV、Pareto/NBD 与 BG/NBD 概念、LTV / CAC 比率、分层应用
8. [行业专题分析场景](/knowledge-map/km-5-analysis-methods/08-industry) — 电商漏斗与复购、内容消费深度、金融 Vintage 分析、SaaS 健康度与扩展收入
