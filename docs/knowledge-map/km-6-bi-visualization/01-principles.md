# 可视化原理

> 好的可视化不是"把数据画出来"，而是**利用人类视觉系统的特性**来高效传递信息。理解底层认知原理，才能在设计图表时做出有理有据的决策。

## 格式塔原则（Gestalt Principles）

格式塔心理学描述了人类如何**自动将视觉元素组织为整体**。在仪表板设计中，这些原则是布局和信息分组的理论基础。

| 原则 | 含义 | 可视化应用 |
|------|------|-----------|
| **接近性（Proximity）** | 距离近的元素被视为一组 | KPI 卡片放在一起表示同一主题 |
| **相似性（Similarity）** | 颜色/形状/大小相似的被视为一组 | 同一类别使用统一色系 |
| **闭合性（Closure）** | 大脑自动补全不完整的图形 | 散点图用轮廓圈出聚类 |
| **连续性（Continuity）** | 视觉倾向于沿平滑路径跟随 | 折线图的趋势线引导阅读 |
| **图底关系（Figure-Ground）** | 自动区分前景和背景 | 强调数据点与背景网格的对比 |

::: tip 实践建议
在 Dashboard 布局时，先用接近性原则将相关 KPI 组合，再用相似性原则统一同类指标的视觉样式。**不要依赖图例来建立关联**——用户不会主动去看图例。
:::

## 预注意属性（Pre-attentive Attributes）

某些视觉属性可以在 **200ms 以内**被大脑并行处理，无需聚焦注意力。这些属性是实现"一眼结论"的关键。

```
高效预注意属性（按效能排序）：
  颜色（色相/饱和度） > 长度/宽度 > 方向 > 形状 > 位置
```

**编码优先级建议**：

| 数据类型 | 适合的预注意属性 |
|---------|----------------|
| 分类（Categorical） | 色相（hue）、形状 |
| 有序（Ordinal） | 饱和度（saturation）、亮度 |
| 数值（Quantitative） | 长度、面积、位置（坐标轴） |
| 异常值检测 | 色相（用高亮色） |

::: warning 常见误区
不要使用超过 **6-8 种** 不同颜色进行类别编码。预注意属性在数量过多时会退化为需要逐个识别的串行处理，失去效率优势。
:::

## 图表选择决策树（Chart Selection Decision Tree）

选择图表的核心逻辑：**数据类型 + 分析目标 → 图表类型**。

```text
你想展示什么？
│
├── 数值大小比较（Comparison）
│   ├── 单个类别 vs 目标 → 柱状图 + 参考线 / Bullet Chart
│   ├── 多类别之间 → 柱状图（排序后）
│   ├── 占比 → 条形图（不要用饼图超过 5 项）
│   └── 排名变化 → 条形图（横向，降序排列）
│
├── 趋势与时间序列（Trend over Time）
│   ├── 连续时间 → 折线图
│   ├── 非连续时间点 → 柱状图
│   ├── 多序列对比 → 多线折线图（≤5 条线）
│   └── 周期模式 → 日历热力图
│
├── 分布（Distribution）
│   ├── 单变量分布 → 直方图
│   ├── 多变量分布 → 箱线图（Box Plot）
│   ├── 数据密度 → 小提琴图（Violin Plot）+ 散点
│   └── 两个变量的关系 → 散点图 + 趋势线
│
├── 构成（Composition）
│   ├── 静态占比 → 堆积柱状图 / Treemap
│   ├── 随时间变化 → 百分比堆积面积图
│   └── 层级关系 → Sunburst / Treemap
│
└── 关联与流动（Correlation / Flow）
    ├── 变量相关性 → 散点图矩阵（Scatter Matrix）
    ├── 地理分布 → 地图（Choropleth / Bubble Map）
    └── 流程/漏斗 → Sankey / Funnel Chart
```

::: info 决策要点
不存在"最正确的图表"，只有**最诚实**和**最易懂**的图表。选择时优先考虑**目标读者的认知负担**而非视觉新颖性。
:::

## 色彩理论（Color Theory）

### 色彩在可视化中的三种角色

1. **分类色（Categorical）** — 区分不同类别，使用色相差异（如 D3 Category10）
2. **顺序色（Sequential）** — 表示数值由低到高，使用单色相的亮度渐变（如浅蓝→深蓝）
3. **发散色（Diverging）** — 表示偏离中心值的方向和程度（如红→白→蓝）

### 配色注意事项

- **色盲友好（Colorblind Friendly）**：避免红绿对比，改用蓝橙或蓝红组合
- **统一语义**：红色=异常/下降，绿色=正常/增长（在中国语境下反向也可，但要统一）
- **背景色**：使用浅灰/白色背景，不要在纯白背景上使用极浅色
- **数据墨水比（Data-Ink Ratio）**：减少非数据墨水（网格线、边框、装饰），让颜色全部分配给数据

```text
好的配色：
  #4E79A7 (蓝)  #F28E2B (橙)  #E15759 (红)  #76B7B2 (青)
  #59A14F (绿)  #EDC948 (黄)  #B07AA1 (紫)  #FF9DA7 (粉)

色盲友好（蓝橙）：
  #2B83BA → #FDAE61 → #D7191C
  (低 → 中 → 高)
```

## 标注基础（Annotation Basics）

好的图表需要**精确的标注**来降低读者的理解成本。

- **标题（Title）**：用陈述句而非名词短语，例如"Q3 销售额同比增长 23%"而非"季度销售额"
- **数据标签（Data Label）**：只在关键数据点标注，避免全部标注造成视觉混乱
- **参考线（Reference Line）**：标注目标值、平均值、阈值，帮助读者快速判断
- **趋势线（Trend Line）**：突出数据模式，配合置信区间
- **异常标注（Anomaly Annotation）**：在异常点添加说明文字，解释"为什么"

::: tip 标注原则
如果读者需要超过 **3 秒** 才能理解图表想表达什么，说明标注不够。好的标注应该让读者在 1 秒内抓住核心信息。
:::

## 无障碍设计（Accessibility Basics）

可视化应当照顾视障和色觉障碍用户：

- **不止依赖颜色**：使用形状、图案纹理（Pattern）辅助区分
- **足够的对比度**：前景/背景对比度至少 4.5:1（WCAG AA 标准）
- **文本可缩放**：确保文字在屏幕放大后依然清晰
- **标题和图例**：确保屏幕阅读器可以正确读取图表信息
- **避免闪烁**：避免高频率闪烁（可能诱发癫痫）
