# KM 6. BI 工具与可视化（BI Tools & Visualization）

> 数据可视化是将分析结果有效传达给决策者的最终环节。本节从**视觉认知原理**出发，深入图表选择、仪表板设计、数据叙事，并覆盖 Tableau、Power BI 和开源 BI 工具的实战技能。

## 章节

1. [可视化原理](/knowledge-map/km-6-bi-visualization/01-principles) — 格式塔原则、预注意属性、图表选择决策树、色彩理论、标注基础、无障碍设计
2. [图表类型详解](/knowledge-map/km-6-bi-visualization/02-chart-types) — 柱状图/折线图/散点图/直方图/箱线图/热力图/树图/瀑布图等使用场景与常见错误、图表选择黄金法则
3. [Dashboard 设计](/knowledge-map/km-6-bi-visualization/03-dashboard-design) — 信息层级与 F 型/Z 型扫描模式、KPI 布局规则、执行型 vs 运营型 Dashboard 设计、交互设计（下钻/筛选/交叉筛选）
4. [Data Storytelling](/knowledge-map/km-6-bi-visualization/04-storytelling) — Context → Conflict → Resolution → Action 叙事结构、Insight → Conclusion → Recommendation 框架、数据演示组织结构、渐进式揭示与强制对比技巧
5. [Tableau 实战](/knowledge-map/km-6-bi-visualization/05-tableau) — 数据连接（Live/Extract）、计算字段、表计算（分区与寻址）、LOD 表达式（FIXED/INCLUDE/EXCLUDE）、参数、集与动作、Dashboard 交互性、性能优化
6. [Power BI 实战](/knowledge-map/km-6-bi-visualization/06-powerbi) — DAX 核心函数（CALCULATE/FILTER/ALL/SUMX）、常用度量值模式、Power Query M 语言、行级安全性 RLS、模型视图设计原则、Gateway 部署
7. [开源方案](/knowledge-map/km-6-bi-visualization/07-open-source) — Metabase（部署/SQL 变量/权限）、Apache Superset（部署/60+ 图表/SQL Lab）、Metabase vs Superset vs Tableau vs Power BI 全面对比与选型建议
