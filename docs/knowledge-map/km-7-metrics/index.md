# KM 7. 业务指标体系（Business Metrics）

> 业务指标体系是将数据能力从"看数"升级为"驱动决策"的关键基础设施。本节从**方法论框架**出发，深入指标管理规范和 OKR/KPI 目标体系，然后覆盖电商、金融、内容、SaaS 四大行业的指标体系最佳实践。

## 章节

1. [指标框架与方法](/knowledge-map/km-7-metrics/01-frameworks) — AARRR、HEART、GSM、北极星指标定义与分解、指标层级（核心/服务/代理）
2. [指标管理](/knowledge-map/km-7-metrics/02-metrics-management) — 指标字典、命名规范、数据血缘、指标上线与下线流程
3. [目标管理 OKR / KPI](/knowledge-map/km-7-metrics/03-okr-kpi) — OKR vs KPI 定位、OKR 写作方法、KPI 树分解、领先与滞后指标
4. [电商行业指标体系](/knowledge-map/km-7-metrics/04-ecommerce) — GMV 分解、转化率体系、复购与留存、购物车分析、库存与供应链
5. [金融行业指标体系](/knowledge-map/km-7-metrics/05-finance) — 资产规模与增长、逾期与风险指标（Vintage 分析）、用户生命周期、LTV/CAC
6. [内容行业指标体系](/knowledge-map/km-7-metrics/06-content) — DAU/MAU 与用户规模、内容消费深度、内容生态（创作者/供需/质量）、变现效率（ARPU/eCPM）
7. [SaaS 行业指标体系](/knowledge-map/km-7-metrics/07-saas) — MRR/ARR、NRR vs GRR、客户健康度、NPS、Time-to-Value
