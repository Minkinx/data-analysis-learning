# 数据治理与质量

> 分析师是数据质量的直接受害者也是守护者。深入参考请见 [KM 10. 数据治理与质量](/knowledge-map/km-10-governance)。

## Data Quality 六维度

| 维度 | 含义 | 常见问题 |
|------|------|---------|
| 完整性 | 数据是否缺失 | 字段为 NULL |
| 准确性 | 数据是否正确 | 金额错误 |
| 一致性 | 跨系统是否一致 | 口径打架 |
| 及时性 | 是否按时到 | T+1 未更新 |
| 唯一性 | 是否有重复 | 重复记录 |
| 有效性 | 是否符合规则 | 手机号格式错误 |

## 分析师怎么做？

- 建表时加上 **数据质量监控规则**
- 关键报表 **双跑验证**（新逻辑 vs 旧逻辑）
- 维护 **指标字典**，统一口径
