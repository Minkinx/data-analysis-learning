# 沟通与协作

## 需求沟通

- 听懂业务需求：区分「要什么」和「解决什么问题」
- BRD 解读：从业务需求文档中提取分析目标和约束条件
- 优先级判断：影响范围 vs 紧急程度 vs 投入成本

## 跨团队协作

- **与产品**：关注功能上线后的数据表现，主动推送洞察
- **与运营**：提供分层标签和策略评估支持
- **与工程**：明确数据口径和取数逻辑，避免反复返工

## 向上汇报

- 汇报结构：背景 → 方法 → 发现 → 建议
- 指标解读：不只是说涨跌，要说明原因和影响
- 用数据讲故事：把数据翻译成业务语言
