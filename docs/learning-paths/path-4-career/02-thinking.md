# 分析思维培养

## 结构化思维

- **MECE 原则**：相互独立，完全穷尽
- **金字塔原理**：结论先行，论据分层
- **假设驱动**：先提假设，再用数据验证

## 业务理解

- 行业研究：产业链、商业模式、竞争格局
- 商业模式画布：价值主张、客户细分、收入来源
- 竞品分析：功能对比、数据表现、策略差异

## 批判性思维

- 避免确认偏误：主动寻找反面证据
- 数据说谎的常见手法：基数操纵、选择性汇报、图表失真
- 总是问：「这个结论还有别的解释吗？」
