# 职业发展

## BI 岗位全景图

| 岗位 | 核心职责 | 技能侧重 |
|------|---------|---------|
| BI 分析师 | 报表、取数、专题分析 | SQL + BI 工具 + 业务理解 |
| 数据分析师 | 深入分析、策略输出 | 统计 + Python + AB测试 |
| 数据运营 | 业务支持、活动分析 | 指标 + 运营思维 |
| 数据产品 | 数据平台产品设计 | 产品思维 + 技术理解 |
| 数据工程师 | 数据管道、数仓建设 | 工程 + 架构 |

## 能力成长路线

- **初级（0-2年）**：SQL 熟练、BI 工具、基础分析
- **中级（2-5年）**：专题分析、指标建设、独立推动
- **高级（5-8年）**：业务策略、团队指导、方法沉淀
- **专家/管理（8年+）**：方向制定、数据文化建设

## 学习资源

- **SQL**：《SQL 必知必会》、LeetCode SQL 题库
- **Python**：《利用 Python 进行数据分析》、Kaggle
- **统计**：《深入浅出统计学》、Coursera 专项课程
- **AB测试**：《Trustworthy Online Controlled Experiments》
- **业务**：《精益数据分析》、《增长黑客》
- **认证**：GBQ（Google Business Intelligence）、CDMP
