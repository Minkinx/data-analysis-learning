IP 3. 统计学与概率题 ​

统计学和概率是数据分析面试中的硬核部分，尤其在涉及 A/B 测试和实验设计时。本章覆盖概率计算、经典概率问题、假设检验和 A/B 测试案例分析。

题目 1：贝叶斯定理 — 疾病检测 ​

问题：某疾病的患病率为 0.1%（即 1000 人中有 1 人患病）。检测方法的灵敏度（真阳性率）为 99%，特异度（真阴性率）为 98%。如果一个人检测结果为阳性，他真正患病的概率是多少？

解答：

定义事件：

  • $D$：患病，$P(D) = 0.001$
  • $T^+$：检测阳性

已知：

  • $P(T^+ | D) = 0.99$（灵敏度）
  • $P(T^- | \neg D) = 0.98$（特异度），即 $P(T^+ | \neg D) = 0.02$

由贝叶斯定理：

$$P(D | T^+) = \frac{P(T^+ | D) \cdot P(D)}{P(T^+ | D) \cdot P(D) + P(T^+ | \neg D) \cdot P(\neg D)}$$

$$P(D | T^+) = \frac{0.99 \times 0.001}{0.99 \times 0.001 + 0.02 \times 0.999} \approx \frac{0.00099}{0.00099 + 0.01998} \approx \frac{0.00099}{0.02097} \approx 4.72%$$

结论：即使检测阳性，真正患病的概率也只有约 4.72%。这是因为疾病本身非常罕见，即使误报率只有 2%，误报的数量也远超真正的患者。

考点：贝叶斯定理的直观理解，先验概率与后验概率的关系，能口算出近似值。

题目 2：期望值 — 抽卡/抽奖问题 ​

问题：一个抽奖活动，抽一次需要 10 元。奖品设置如下：

  • 一等奖（概率 0.1%）：价值 5000 元
  • 二等奖（概率 1%）：价值 500 元
  • 三等奖（概率 10%）：价值 20 元
  • 谢谢参与（概率 88.9%）：0 元

问：抽一次奖的期望收益是多少？这个活动对玩家公平吗？

解答：

期望收益 = Σ (概率 × 奖品价值)

$$E = 0.001 \times 5000 + 0.01 \times 500 + 0.1 \times 20 + 0.889 \times 0$$

$$E = 5 + 5 + 2 + 0 = 12 \text{元}$$

每次抽奖的期望收益为 12 元，大于成本 10 元，所以从期望角度看对玩家有利。

考点：期望值计算。注意面试官可能追问：为什么实际中这种活动还是稳赚的？（因为大数定律需要大量玩家，部分玩家可能永远抽不到一等奖）。

题目 3：p-value 的理解与误用 ​

问题：请解释 p-value 的含义。一个 A/B 测试得到 p-value = 0.03，以下哪种理解是正确的？

  1. 实验组和对照组有 97% 的概率存在真实差异
  2. 如果零假设为真，观察到当前或更极端结果的概率是 3%
  3. 有 3% 的概率零假设是正确的

解答：

正确理解是第 2 种：p-value = 0.03 表示"在零假设（两组无差异）为真的前提下，观察到当前结果或更极端结果的概率是 3%"。

常见误用辨析：

  1. ❌ "有 97% 的概率存在真实差异" — p-value 不是 H₁ 为真的概率
  2. ✅ 正确
  3. ❌ "有 3% 的概率零假设是正确的" — p-value 不是 H₀ 为真的概率

面试追问：p-value = 0.03 可以拒绝零假设吗？

回答框架：

  • 如果显著性水平 α = 0.05，则 p < α，可以拒绝 H₀，差异有统计学意义
  • 但"统计显著"不等于"实际显著"，还需要看效应量 (Effect Size)
  • 样本量很大时，微小差异也可能"统计显著"
  • 同时要考虑多重比较问题

考点：p-value 的精确定义，区分统计显著和实际显著，了解 p-hacking 问题。

题目 4：A/B 测试样本量计算 ​

问题：假设你在设计一个 A/B 测试，当前转化率为 10%。你希望检测出 1 个百分点的绝对提升（即从 10% 到 11%），显著性水平 α = 0.05，统计功效 1-β = 0.80。每组需要多少样本量？

解答：

使用近似公式：

$$n = \frac{(Z_{\alpha/2} + Z_{\beta})^2 \times [p_1(1-p_1) + p_2(1-p_2)]}{(p_2 - p_1)^2}$$

其中：

  • $p_1 = 0.10$（对照组）
  • $p_2 = 0.11$（实验组）
  • $Z_{\alpha/2} = 1.96$（双侧 95% 置信水平）
  • $Z_{\beta} = 0.84$（80% 功效）

$$n = \frac{(1.96 + 0.84)^2 \times [0.1 \times 0.9 + 0.11 \times 0.89]}{(0.01)^2}$$

$$n = \frac{7.84 \times [0.09 + 0.0979]}{0.0001}$$

$$n = \frac{7.84 \times 0.1879}{0.0001} \approx \frac{1.473}{0.0001} \approx 14,730$$

每组需要约 14,730 个样本，两组共约 30,000 样本。

简化经验法则：

  • 基准转化率越低，所需样本越大
  • 想检测的效应越小，所需样本越大（与效应量的平方成反比）
  • 提高功效或降低 α 都需要更大的样本

考点：样本量计算公式的推导和理解，能够根据实际情况做近似估算。

题目 5：辛普森悖论（Simpson's Paradox） ​

问题：某公司在两个渠道投放广告，数据如下：

渠道A 方案点击率B 方案点击率
搜索广告5% (500/10000)4% (80/2000)
信息流广告3% (150/5000)2.5% (200/8000)
总体4.33% (650/15000)2.8% (280/10000)

可以看到：在搜索广告和信息流广告中，A 方案的点击率都高于 B 方案，但总体来看 B 方案的点击率却高于 A 方案。请解释这是什么现象？原因是什么？

解答：

这就是经典的辛普森悖论。

原因：B 方案的流量分配偏向于高点击率的搜索广告（80% 在搜索广告 vs A 方案只有 10%），导致 B 方案的整体加权平均被拉高。

关键洞察：

  • 当分组比较（segmented）和总体比较（aggregated）结论相反时，往往是**混淆变量 (confounding variable)**在起作用
  • 本例的混淆变量是"渠道分配比例"——两个方案在各渠道的流量占比差异巨大

面试回答框架：

  1. 识别现象：分组趋势 vs 总体趋势相反
  2. 分析原因：找到混淆变量（通常是样本量分配不均）
  3. 正确做法：分层分析 (Stratified Analysis) 或使用标准化率
  4. 业务启示：做 A/B 测试时确保各组流量分配策略一致

考点：辛普森悖论的识别和解释，分层分析的思路。

题目 6：经典概率 — 抛硬币问题 ​

问题：连续抛一枚公平硬币 100 次。

  1. 得到恰好 50 次正面的概率是多少？
  2. 获得至少 60 次正面的概率是多少？

解答：

问题 1：二项分布 $X \sim B(100, 0.5)$ $$P(X = 50) = C_{100}^{50} \times (0.5)^{100} \approx \frac{1}{\sqrt{50\pi}} \approx 0.0796 \approx 8%$$

使用斯特林近似或直接计算约为 7.96%。

问题 2：可以用正态近似 $N(\mu=np=50, \sigma=\sqrt{np(1-p)}=5)$ $$P(X \geq 60) = P(Z \geq \frac{60 - 50}{5}) = P(Z \geq 2) \approx 0.0228 \approx 2.28%$$

连续性校正后更精确：$P(X \geq 59.5) = P(Z \geq 1.9) \approx 0.0287$

Python 精确计算：

python
from scipy import stats

# 问题 1
p_50 = stats.binom.pmf(50, 100, 0.5)
print(f"恰好 50 次正面: {p_50:.4f}")  # ≈ 0.0796

# 问题 2
p_60_or_more = 1 - stats.binom.cdf(59, 100, 0.5)
print(f"至少 60 次正面: {p_60_or_more:.4f}")  # ≈ 0.0284

考点：二项分布、正态近似、连续性校正、中心极限定理的应用。

题目 7：假设检验 — 两组转化率对比 ​

问题：A/B 测试数据如下：

  • 对照组 (A)：10000 人访问，转化 500 人，转化率 5%
  • 实验组 (B)：10000 人访问，转化 550 人，转化率 5.5%

请使用 Z 检验判断 B 方案是否显著优于 A 方案（α = 0.05）。

解答：

步骤 1：建立假设

  • $H_0: p_B = p_A$（两组转化率无差异）
  • $H_1: p_B \neq p_A$（双侧）或 $p_B > p_A$（单侧）

步骤 2：计算合并比例 $$\hat{p} = \frac{500 + 550}{10000 + 10000} = \frac{1050}{20000} = 0.0525$$

步骤 3：计算 Z 统计量 $$Z = \frac{\hat{p}_B - \hat{p}_A}{\sqrt{\hat{p}(1-\hat{p})(\frac{1}{n_A} + \frac{1}{n_B})}}$$

$$Z = \frac{0.055 - 0.05}{\sqrt{0.0525 \times 0.9475 \times (\frac{1}{10000} + \frac{1}{10000})}}$$

$$Z = \frac{0.005}{\sqrt{0.00000995}} \approx \frac{0.005}{0.003154} \approx 1.585$$

步骤 4：结论

  • 单侧检验的 p-value ≈ 0.056
  • 因为 0.056 > 0.05，在 α = 0.05 水平上不能拒绝零假设
  • 即没有充分证据表明 B 方案显著优于 A 方案

Python 实现：

python
from statsmodels.stats.proportion import proportions_ztest
import numpy as np

count = np.array([550, 500])
nobs = np.array([10000, 10000])
z_stat, p_value = proportions_ztest(count, nobs, alternative='larger')
print(f"Z = {z_stat:.3f}, p-value = {p_value:.4f}")

考点：比例 Z 检验的完整步骤、p-value 解读、统计显著 vs 实际显著的区别。注意即使 5.5% > 5%，差异可能是随机波动导致的。

题目 8：贝叶斯 A/B 测试 ​

问题：对比经典的频率学派 A/B 测试，贝叶斯 A/B 测试有什么不同？请简要说明贝叶斯方法的优势和劣势。

解答：

核心区别：

维度频率学派贝叶斯学派
概率解释长期频率信念程度
参数固定（未知）常数随机变量，有分布
先验信息不使用需要设定先验
输出p-value、置信区间后验分布、可信区间
停止规则需要预先固定样本量可随时停止评估
解释p-value 易误读可直说"B 比 A 好的概率是 X%"

贝叶斯 A/B 测试流程：

python
import numpy as np
from scipy import stats

# 先验：Beta(1, 1) 均匀分布
alpha_prior, beta_prior = 1, 1

# 观测数据：A 组 500/10000，B 组 550/10000
a_conv, a_total = 500, 10000
b_conv, b_total = 550, 10000

# 后验分布：Beta(alpha + 成功数, beta + 失败数)
a_posterior = stats.beta(alpha_prior + a_conv, beta_prior + a_total - a_conv)
b_posterior = stats.beta(alpha_prior + b_conv, beta_prior + b_total - b_conv)

# 蒙特卡洛采样：B 优于 A 的概率
n_samples = 100000
a_samples = a_posterior.rvs(n_samples)
b_samples = b_posterior.rvs(n_samples)
prob_b_better = (b_samples > a_samples).mean()
print(f"B 优于 A 的概率: {prob_b_better:.2%}")

优势：

  • 直观的概率解释：B 优于 A 的概率为 X%
  • 可以充分利用先验信息（如历史实验数据）
  • 支持实时监控和提前停止
  • 适合小样本场景

劣势：

  • 需要选择合适的先验分布（不当的先验可能导致偏差）
  • 计算复杂（MCMC 采样），但近年计算能力已不是问题
  • 先验的选择一定程度上有主观性
  • 在合规性要求高的场景（如临床试验），频率学派仍是主流

考点：贝叶斯 vs 频率学派的核心差异，能结合实际场景讨论各自的适用性。
